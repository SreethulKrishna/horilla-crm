Quick Docker Installation

bash 
$ git clone https://github.com/horilla/horilla-crm.git
$ cd horilla-crm
$ docker-compose up --build

Manual Development Server Setup

bash 
# Apply relational migrations
$ python manage.py migrate

# Initialize administrative profiles
$ python manage.py create_horilla_user

# Launch the asynchronous development core 
$ python manage.py runserver
