Open Source Enterprise CRM

Horilla CRM Built for Modern Businesses

Free and open-source CRM platform powered by Django, HTMX, and PostgreSQL for lead management, sales pipelines, customer engagement, campaigns, analytics, and workflow automation.

GitHub Repository Live Demo

Core Features

Enterprise-grade CRM modules designed for customer management, sales growth, marketing campaigns, analytics, and real-time collaboration.

Lead & Opportunity Management

Track leads, manage opportunities, forecast revenue, and automate sales pipelines with customizable stages.

Accounts & Contacts

Manage organizations and customer contacts with relationship tracking and activity timelines.

Campaign Analytics

Create marketing campaigns, monitor ROI, and track conversions from multiple lead sources.

Real-time Notifications

WebSocket-powered live notifications, alerts, and activity updates across the platform.

Interactive Dashboards

Visual reports, widgets, analytics, and exportable business intelligence data.

Multi-language Support

Supports 25+ languages including English, Arabic, German, French, and Korean.

Quick Installation

shell 
            $ git clone https://github.com/horilla-opensource/horilla-crm.git $ cd horilla-crm $ docker-compose up --build

Quick Start

shell 
            
              # Run migrations python manage.py migrate

              # Create admin user python manage.py create_horilla_user

              # Start development server python manage.py runserver

Technology Stack

Django 6.0+

Modern Python backend with scalable architecture and enterprise-ready security features.

HTMX + TailwindCSS

Fast dynamic interfaces without heavy frontend frameworks or SPA complexity.

PostgreSQL

Optimized relational database support with indexing and scalable query performance.

Docker Ready

Production-ready Docker and Docker Compose setup with optional Nginx integration.
